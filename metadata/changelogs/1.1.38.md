# 1.1.38

## Changes

- Right-click a Vortex Sigil with a Tabula Rasa to make it stop pulling players. Mobs are still pulled in. Right-click it with an empty hand to take the Tabula back.

## Fixes

- Addons that grant Sentient Armor experience through the Neo Vitae API can now start a new upgrade. Before, only upgrades the armor already had at level 1 or higher gained experience, so upgrades like Animus's Arcane Channeling and Source Attunement never started.
